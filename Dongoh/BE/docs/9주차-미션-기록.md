# BE 9주차 — Swagger 문서화와 자동화 테스트

## 추가·변경한 내용

- Springdoc OpenAPI를 추가하고 `/swagger-ui.html`, `/v3/api-docs`를 인증 예외 경로로 열었다.
- 회원가입·로그인처럼 공개된 API와 토큰이 필요한 평점·즐겨찾기·내 정보 API를 문서에서 구분했다.
- 요청 DTO에 필드 설명과 예시 값을 추가했다.
- 즐겨찾기 Service 단위 테스트 2개와 API 통합 테스트 4개를 작성했다.
- 필수 미션으로 평점 Service 단위 테스트 2개와 API 통합 테스트 2개를 작성했다.

## 테스트한 내용

### 즐겨찾기 단위 테스트

- 즐겨찾기 등록 성공 시 저장 결과를 반환하는지 확인했다.
- 같은 영화를 중복 등록하면 `FAVORITE409_1` 예외가 발생하는지 확인했다.

### 즐겨찾기 통합 테스트

- 토큰 없이 등록하면 401과 `AUTH401_2`를 응답하는지 확인했다.
- 토큰을 담아 등록하면 201과 영화 ID를 응답하는지 확인했다.
- 중복 등록하면 409와 `FAVORITE409_1`을 응답하는지 확인했다.
- 등록하지 않은 영화의 즐겨찾기 여부가 200과 `false`인지 확인했다.
- `/v3/api-docs`가 토큰 없이 열리는지도 함께 확인했다.

### 평점 필수 미션 테스트

- 같은 영화에 평점을 중복 등록하면 `RATING409_1`이 발생하는지 확인했다.
- 다른 회원의 평점을 수정하면 `RATING403_1`이 발생하는지 확인했다.
- 토큰 없이 `POST /ratings`를 호출하면 401인지 확인했다.
- 토큰을 담아 `POST /ratings`를 호출하면 201과 `COMMON201`을 응답하는지 확인했다.

## 트러블 슈팅

**이슈**

Swagger 주소에 접속했을 때 인증 인터셉터가 요청을 막아 401을 응답했다.

**문제**

기존 인터셉터가 모든 경로를 잠그고 있었고 새로 생긴 Swagger UI와 OpenAPI JSON 경로가 공개 목록에 없었다.

**해결**

`/swagger-ui.html`, `/swagger-ui/**`, `/v3/api-docs/**`를 인터셉터 예외 경로에 추가하고, 통합 테스트로 `/v3/api-docs`가 토큰 없이 200을 응답하는지 고정했다.
